## Go / No-Go 标准

只有以下条件全部满足才提交：

- [ ] 两段必交视频已录制并完整播放检查。
- [ ] 源码、固件、开发日志和使用指南均在最终目录中。
- [ ] 视频与文档没有真实 Wi-Fi 密码或私人信息。
- [ ] 视频中明确说明“舵机模拟门锁”“不做人脸身份识别”。
- [ ] 文件名、作品名和版本日期一致。
- [ ] 最终压缩包大小满足提交平台限制。

## 回退方案

如果录制前发现严重回归：

1. 保留当前已验证固件和发布包，不立即覆盖。
2. 使用最终发布包中的三个 `.bin` 文件恢复 P4。
3. 重新运行 BOOT、接听、音视频、开门、挂断、二次呼叫五项冒烟测试。
4. 只有恢复版本通过后才继续录制。

负责人：参赛者。预计恢复和冒烟测试时间：20～40 分钟。
