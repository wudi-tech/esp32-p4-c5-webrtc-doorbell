## 作品一句话介绍

本作品在 WT99P4C5-S1（ESP32-P4 + ESP32-C5）开发板上实现了局域网 WebRTC 智能门铃：支持板端摄像头到浏览器实时视频、双向音频、BOOT 实体按键呼叫、浏览器接听/挂断、舵机模拟开锁及语音提示、LD2450 雷达人员接近检测、摄像头人体/人脸存在辅助检测和中文网页状态展示。

## 真实性边界

- 舵机当前用于模拟门锁动作，尚未连接真实门锁机构。
- 摄像头只判断是否有人并显示检测框与置信度，不进行身份识别。
- LD2450 输出最多三个目标的二维坐标、速度和进入/离开事件，不是三维点云雷达。
- 配套显示屏尚未集成到最终门铃 UI，代码保留了未来扩展接口。
- 当前实现面向同一局域网内的单浏览器客户端。
