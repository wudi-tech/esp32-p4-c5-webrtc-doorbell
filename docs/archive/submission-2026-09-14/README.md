# 最终提交目录说明

建议按编号顺序上传或提交：

1. `01_可运行作品固件`：公开版 ESP32-P4 固件、烧录脚本、烧录说明和校验值。
2. `02_项目完整源码_WT99P4C5_WebRTC_Doorbell.zip`：包含本次修改后的完整源码，不包含构建缓存、Git 历史和私人 Wi-Fi 配置。
3. `03_开发日志.md`：完整复刻与调试过程。
4. `04_使用指南.md`：ESP-IDF 开发环境、接线、构建、烧录和使用说明。
5. `03_提交文档/03_提交源码完备性审计.md`：逐文件职责、构建接入、自动检查和硬件验证边界。
6. `05_代码录屏讲解`：按 10 分钟上限脚本录制的横屏、清晰收音代码讲解视频。
7. `06_项目使用流程演示`：横屏拍摄的完整功能演示视频。
8. `07_复刻过程记录_加分项`：硬件搭建、故障定位、代码调试等过程视频。
9. `08_提交前检查表.md`：提交前逐项确认。

作品口径必须保持一致：

- 已完成本地局域网 WebRTC 智能门铃原型。
- 摄像头完成“有人/人脸存在”语义判断，不做人脸身份识别。
- 雷达输出二维目标坐标和进入/离开事件，不宣称三维点云。
- 舵机模拟开锁，未安装真实门锁。
- 配套显示屏保留为未来扩展，当前作品使用浏览器作为交互界面。

视频文件建议使用 MP4/H.264、1920×1080、30 fps。录制后用 `01_代码录屏讲解脚本.md`、`02_项目使用流程演示脚本.md` 和 `03_复刻过程加分视频脚本.md` 对照检查内容。
