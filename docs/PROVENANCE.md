## 不上传的内容

- 招新签到表、人员名单、相关预览及其处理脚本：与门铃项目无关，包含个人数据。
- `node_modules`、缓存、临时目录、工作树、编辑器运行状态、本机 Git 历史：不属于项目交付内容。
- 第三方参考示例视频与模板：属于复刻过程中的外部参考，不作为本人的作品发布。
- 两个旧源码/全量提交 ZIP：展开内容已在代码、文档、固件和 Release 视频中归档，避免重复存储与旧版本说明混淆。没有从大 ZIP 再引入未经检查的内容。
- 私有 `settings.local.h`、本机构建目录、`sdkconfig`、`managed_components`、含本机路径的依赖锁定文件：按源码快照原有边界排除。

本次未遍历采集整个电脑的开发目录；归档范围为此项目工作目录内已经存在的交付快照和配套材料。

## 历史说明的读法

历史材料保留原始日期、旧目录名、当时测试状态、字节大小和绝对路径等上下文。有些叙述互相矛盾或已被后续代码分析纠正；不能把“参与编译”“单元测试通过”“历史实机确认”合并成当前全系统验收。公开总览与 [PROJECT_STATUS.md](PROJECT_STATUS.md) 已列明重要差异。

## 发布组织

代码、文档、图纸、硬件 PDF、小型库与固件进入 Git；大型 MP4 放在 Release。标签 `archive-2026-10-24` 表示此次资料归档，不表示在当天完成了新的硬件版本或性能测试。
