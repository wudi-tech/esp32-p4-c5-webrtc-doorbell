# MG90S 舵机供电与安全

## 已验证服务器参数

- 模范家庭: MG90S/GX90S 金属齿轮模拟伺服器
- 供应: 4.8–6.0 V
- PWM: 50赫兹 (20毫秒期间)
- 0度：: 五百个
- 90度( 90度): 我们1500
- 180°: 我们2500
- 无负载速度 4.8 V: 0.11 s/60 学位
- 显示当前: 约1 A
- 控制信令: WT99P4C5-S1 J6 标点 20, ESP32-P4 GPIO32

## 电线

伺服器使用独立调节的5V供应. 董事会仍然有动力
联合国 USB 连接。

| Servo铅 | 连接 |
| --- | --- |
| 黄色 (PWM) | WT99P4C5-S1 J6 GPIO32 |
| 红色 (+5 V) | 独立监管的5项产出 |
| 褐色 (GND) | 独立供应 GND |
| 董事会 GND | 独立供应 GND (共同立场) |

不连接服务器红色线索到棋盘 3.3 五号铁路. 不参加
外部+5 V铁路到板+5 V铁路. 仅加入理由。

## 固件行为

- Boot/default 状态: `LOCKED`, 五百个 (0度：)
- 开放动议: 我们2500 (180°), 500毫米津贴
- 解锁: 5秒钟
- 关闭运动: 五百个 (0度：), 500毫米津贴
- 活动周期内重复的命令为偶数
- 驱动程序， 队列， 或 PWM 输入更新错误 `FAULT`

服务器没有位置或当前反馈. `UNLOCKED` 联合国 `LOCKED` 说
完成相应的指挥和动作津贴; 他们没有
证明机械连接达到了其位置. 机械干扰
检测需要限制开关， 位置传感器， 或当前传感器。

## 引入顺序

1. 保持服务 horn/linkage 已卸载， 用于第一次电力运行。
2. 先给板子供电，确认 `DOOR_LOCK` 初始化日志。
3. 应用独立的伺服器供应并确认启动位置。
4. 发送一个浏览器 `Open Door` 命令和观察完整 open/hold/close
   周期。
5. 如果服务器聊天， 立即取消电源， 摊位， 变得热， 或
   棋盘重排。
6. 仅在卸下周期过后附加链接。
7. 运行50个装入周期并记录重排， 摊位， 状态错误， 供应
   电压浸泡。
