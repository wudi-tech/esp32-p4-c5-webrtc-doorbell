## 任务5期间应用的引入修正

- 选中 UART0 作为主控制台，因为 COM5 是棋盘的CP210x
  UART 桥; USB Serial/JTAG 仅生产 ROM 输出于 COM5。
- 已禁用的主机 `SPIRAM_TRY_ALLOCATE_WIFI_LWIP` 对于此远程-Wi-Fi 设置。
  这恢复了供应商测试 C5 配置文件 (静态 RX 10, 动态 TX 32,
  RX BA 窗口 6) 防止 `esp_wifi_init` 从返回
  `ESP_ERR_NO_MEM`.
