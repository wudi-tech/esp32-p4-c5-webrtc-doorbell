## 二、三件必须先知道的事（详见主手册第 6.4 节、第 13 章）

1. **开门语音在默认构建下大概率不会响。** 提示音混音要求 16000 Hz，而默认通话音频是 G711A 8000 Hz；混音分支和静音兜底线程都不会输出，且函数仍返回 0，串口不报错。实测日志为证：通话中渲染器打开的是 8000 Hz。演示前请先实机复测，或选择一种修法（启用 OPUS / 把 `open.aac` 预处理目标改成 8 kHz）。
2. **没有"中文语音提示"。** 三段提示音是预录 AAC，开门台词是英文 "Doors open, come in please"；中文只存在于网页 UI。
3. **`doorbell_status.c` 与 `PEDESTRIAN_DETECTED` 是未接线/死代码**，网页状态实际来自 SSE 的 `vision_state` / `radar_event`；另外开门命令当前无鉴权、TLS 为示例自签名证书（2028-10-14 到期）。这些属于"可信局域网 Demo"级安全边界，建议主动声明。
