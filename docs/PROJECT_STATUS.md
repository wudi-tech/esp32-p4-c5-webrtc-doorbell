## 继续深化的方向

1. 统一音频采样率与提示音输出策略，并实机回归接听、通话中开门、挂断和再次呼叫。
2. 统一实际业务状态模型，清理或接入未使用的状态模块，再同步审计文档。
3. 在重新确认的构建环境中保存可移植的依赖版本记录，建立源码提交与固件校验值的对应。
4. 采集多轮重连、呼叫延迟、误触发率与连续运行数据；真实锁体和鉴权属于后续独立工作。
